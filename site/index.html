    How this page ships

    1. 01
      Push

      I push to main. That's the only manual step.

    2. 02
      Lint

      ESLint checks the JavaScript. A missing semicolon fails the run and nothing deploys.

    3. 03
      Package

      A build script copies the site into _site/ and stamps the commit ID.

    4. 04
      Publish

      GitHub Actions uploads the package and deploys it to Pages.
